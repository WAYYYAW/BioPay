## 更新内容

- 内置 Class 1 面容兼容，无需另装“指纹面容伪装”模块。此类设备需启用 LSPosed 的“系统框架（system）”作用域，并重启手机。
- 修复旧认证回调影响新支付会话、保存失败仍提示成功，以及取消后界面未正常恢复等问题。
- 优化自动密码输入、支付会话清理和日志保存，减少重复处理及主线程等待。
- 更新使用说明和支付流程图。
- Release 下载仅提供签名正式版 APK；debug APK 保留在 Actions 的 CI artifacts。

## 升级须知

**1.1.0 更换了正式版签名密钥，不能直接覆盖旧签名版本。** 请先卸载旧版 BioPay，再安装新版。安装后重新确认 LSPosed 作用域并重启手机；如设置未保留，请重新录入支付密码。

### Upgrade notice (English)

**Version 1.1.0 uses a new release signing key and cannot replace a version signed with the old key.** Uninstall the old BioPay version, install the new one, confirm the LSPosed scopes, and reboot your phone. Enter your payment password again if the settings were not retained.
